# AkerGate - Cloudflare Worker Deployment Guide
### Serverless, 100% Free Forever, Zero Maintenance

This directory contains the ready-to-deploy Cloudflare Worker script (`worker.js`) that handles Telegram commands and generates 7-digit offline-compatible OTPs synchronized with your host hardware clock (RTC).

---

## Why Cloudflare Workers?
* **100% Free:** Free tier provides 100,000 requests per day (infinitely more than needed for personal authentication).
* **Serverless:** No Linux server to manage, patch, or keep online.
* **Instant Cold Starts (< 5ms):** Cloudflare runs on V8 isolates at 300+ edge locations worldwide.

---

## Step-by-Step Deployment (2 Minutes - Zero CLI Required)

### Step 1: Create Your Telegram Bot
1. Open Telegram and message `@BotFather`.
2. Send `/newbot`, name your bot (e.g. `MyAkerGateBot`), and choose a username ending in `bot`.
3. Copy the HTTP API token provided by BotFather (`BOT_TOKEN`).
4. Message `@userinfobot` on Telegram to get your numeric account ID (`ALLOWED_CHAT_ID`).

### Step 2: Deploy to Cloudflare Workers
1. Go to the [Cloudflare Dashboard](https://dash.cloudflare.com/) and create a free account if you haven't already.
2. In the left navigation, click **Compute (Workers & Pages)** -> **Create Application** -> **Create Worker**.
3. Name your worker (e.g. `akergate-bot`) and click **Deploy**.
4. In the top right corner, click **Edit code**.
5. Delete the default sample code and replace it entirely with the contents of `worker.js`.
6. Click **Deploy** (in the top right).

### Step 3: Add Your Secrets
1. Go back to your Worker's page, navigate to the **Settings** tab -> **Variables and Secrets**.
2. Click **Add** under *Secrets* and add these three environment variables:
   * `BOT_TOKEN`: The API token from `@BotFather`.
   * `ALLOWED_CHAT_ID`: Your numeric user ID from `@userinfobot`.
   * `SHARED_SECRET`: The Base32 secret generated by AkerGate (run `akergate` -> Tab 4, or `cat /etc/akergate/telegram_secret.key`).
3. Click **Deploy** / **Save**.

### Step 4: Link Telegram to Your Worker (One-Time Webhook)
Cloudflare Workers receive Telegram updates via Webhooks. To activate it, simply open your web browser and visit this URL (substituting your actual values):

```text
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://<YOUR_WORKER_NAME>.<YOUR_CLOUDFLARE_SUBDOMAIN>.workers.dev
```

You will see this JSON confirmation in your browser:
```json
{"ok": true, "result": true, "description": "Webhook was set"}
```

## Testing Your Bot
Open your bot on Telegram and send:
* `/otp` : Generates a 7-digit temporary passcode.
* `/lockdown` : Triggers emergency lockdown options.
* `/status` : Verifies cloud timestamp and interval health.
