# AkerGate - Official Telegram Serverless Bot

Deploy and run your AkerGate Offline OTP bot **directly on Telegram's official Serverless infrastructure** (`tgcloud.ai`) with zero external servers, zero containers, and zero maintenance.

Official Telegram Serverless Documentation: [https://core.telegram.org/bots/serverless](https://core.telegram.org/bots/serverless)

---

## Key Benefits

1. **Native Telegram Hosting**: No Cloudflare, no AWS, no VPS required. Code runs inside Telegram's secure V8 isolates adjacent to Telegram messaging servers.
2. **Sub-5ms Latency**: Instantaneous responses to `/otp` commands.
3. **100% Free**: Built-in to Telegram Bot platform.
4. **Auto-Routing**: No manual webhook setup or domain DNS configuration required.

---

## Deployment Steps (خطوات النشر والتشغيل)

### 1. Enable Serverless on BotFather (تفعيل الخدمة من بوت فاذر)
1. Open Telegram and message **@BotFather**.
2. Send `/mybots` and select your bot.
3. Click **Serverless** in the menu.
4. Click **Turn On** to enable Telegram Serverless hosting.
5. Copy your CLI Access Token.

### 2. Configure Credentials (ضبط البيانات السرية)
Open `tgcloud/config.js` and set:
- `ALLOWED_CHAT_ID`: Your numeric Telegram User ID (retrieved from `@userinfobot`).
- `SHARED_SECRET`: The Base32 shared secret key generated by AkerGate (shown in the TUI under `Multi-Factor Authentication -> Telegram Bot & Offline OTP Settings`).

### 3. Deploy via tgcloud CLI (الرفع بنقرة واحدة)
From this directory:

```bash
cd /home/yuki/Projects/AkerGate/telegram_backends/telegram_serverless

# Login to your Telegram Serverless account (first time only)
npx @tgcloud/cli login

# Push the handler code to Telegram infrastructure
npx @tgcloud/cli push
```

### 4. Verify & Test (الاختبار)
Open your bot in Telegram and send:
- `/start` : Check bot activation.
- `/otp` : Receive your live 7-digit Windowed Offline OTP.
- `/status` : Verify epoch synchronization.
